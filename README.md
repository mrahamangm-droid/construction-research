# Construction Research — AI-Enhanced Leadership & Delivery

Open-access research on artificial intelligence in construction leadership, project
delivery and infrastructure economics. This repository is the reference point for the
**GCLM / AI-GCLM** framework line and collects the published papers with their DOIs.

## Overview

The work here develops a single question across several papers: **how should construction
leaders make decisions when AI can do part of the analysis?**

The **Global Construction Leadership Model (GCLM)** sets out the leadership structure.
**AI-GCLM** extends it with a decision-support layer, placing AI-assisted analysis inside
the delivery process while keeping judgement, accountability and people-centred delivery
with the human leader rather than the system. Later papers apply the model to
mega-infrastructure delivery, executive decision-making, and cross-market economics.

## Framework summary

**GCLM 2.0** — a leadership model for global construction organisations, structured
around intelligent and people-centred project delivery.

**AI-GCLM** — the AI-enhanced extension. Adds a decision-support layer for executive
judgement, applied across:

- generative AI in executive decision-making (Leadership 5.0)
- regenerative mega-infrastructure delivery
- knowledge transfer, advisory and talent networking (PGAN ecosystem model)
- cross-market construction economics (CMEC, UAE / UK / USA)
